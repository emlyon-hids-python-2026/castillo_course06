# castillo_course06

Short description of the project: what it does and why.

## Installation

```bash
git clone https://github.com/emlyon-hids-python-2026/castillo_course06.git
cd castillo_course06
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
